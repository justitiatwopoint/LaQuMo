LaQuMo Model Architecture

How LaQuMo seamlessly bridges quantum Hilbert spaces with high-dimensional embedding spaces in transformer language models.

01

Quantum State Embedding Layer

Maps high-dimensional discrete tokens into parameterized continuous Qubit state vectors.

\(|\psi_i\rangle = R_y(\theta_i) R_z(\phi_i) |0\rangle\)
02

Variational Quantum Circuit (VQC) Ansatz

Multi-layer parameterized CNOT and Hadamard gates generating full quantum entanglement across token registers.

\(U(\vec{\theta}) = \prod_{l=1}^L \left[ \bigotimes_{j=1}^n R_x(\theta_{l,j}) \cdot \text{CNOT}_{j, j+1} \right]\)
03

Quantum Multi-Head Self-Attention (Q-MHA)

Calculates overlap inner products \(\langle \psi_Q | \psi_K \rangle\) directly in physical quantum hardware.

\(\text{Attention}(Q,K,V) = \text{softmax}\left( \frac{|\langle \psi_Q | \psi_K \rangle|^2}{\sqrt{d_k}} \right) V\)
04

Classical Transformer Decoder Backbone

Decodes measured Pauli expectation values \(\langle Z_i \rangle\) into discrete generated outputs.

\(y_{next} = \text{Softmax}(W_o \cdot \vec{\langle Z \rangle} + b)\)

Developer API & Playground

Integrate LaQuMo directly into your scientific computing pipelines using PyTorch, Qiskit, or REST API. 

import torch
from laqumo import LaQuMoForCausalLM, LaQuMoTokenizer

# Initialize 100-Qubit Hybrid Large Quantum Model
model = LaQuMoForCausalLM.from_pretrained(
    "laqumo-labs/LaQuMo-7B-Quantum-v1",
    qubits=100,
    quantum_backend="qiskit.aer_simulator",
    device_map="auto"
)
tokenizer = LaQuMoTokenizer.from_pretrained("laqumo-labs/LaQuMo-7B")

# Quantum Attention Inference
prompt = "Compute ground state energy of Hamiltonian H = H_0 + \\lambda V"
inputs = tokenizer(prompt, return_tensors="pt").to("cuda")
output = model.generate(**inputs, max_new_tokens=256, temperature=0.2)

print(tokenizer.decode(output[0]))
