**LaQuMo (Large Quantum Model)** is a state-of-the-art hybrid quantum-classical artificial intelligence architecture designed for quantum chemistry simulation, combinatorial optimization, and cryptographic reasoning.

This repository contains the interactive scientific web application showcase for LaQuMo featuring a **dark obsidian monochromatic theme** with glassmorphism, mathematical LaTeX notation, and live quantum state vector simulation.

## 🚀 Deployment to GitHub Pages with Custom Domain

To host your site directly on **GitHub Pages** with your custom domain:

1. Follow the step-by-step instructions in [`GITHUB_PAGES_DOMAIN_GUIDE.md`](GITHUB_PAGES_DOMAIN_GUIDE.md).
2. Configure 4 Apex `A` Records and 1 `CNAME` Record at your third-party domain registrar.
3. Enable GitHub Pages in **Settings > Pages**.
